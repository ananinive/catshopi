# Catshopi
Aplicativo que oferece produtos e serviços para gatos.

Funcionamento: 

O usuário vai entrar no app e vai aparecer a tela de cadastro, logo após, ele acessa a tela inicial, onde vai ter as opções para menu, perfil, produtos e serviços.

TELA DE CADASTRO: Pede as seguintes informações: Do pet: nome do pet, idade, peso, porte, raça e sexo. Do cliente: nome, email, telefone e senha.

TELA INICIAL: Contém opções como: menu para suas informações, produtos (divididos por categorias), serviços e perfil.

PRODUTOS: Mostra opções como: ração, brinquedos, higiene, acessórios e farmácia.

SERVIÇOS: Opções como: banho e tosa, vacinação e consulta veterinária;
